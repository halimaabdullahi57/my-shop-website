# Halima Collection Website

A beginner-friendly online shop website project built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and shop content
- `style.css` — colours, layout and responsive styling
- `script.js` — mobile navigation, current year and demo enquiry form

## How to open
1. Extract `halima_collection_website.zip`.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Customise before publishing
- Replace the demo category panels with real product photographs.
- Add your business phone number, WhatsApp link, social media links and actual product prices.
- Connect the enquiry form to a real form service or backend. It currently displays a demo confirmation only.
- Test the site on a phone and desktop before publishing.

This is a front-end demonstration website. It does not process payments, manage stock or send customer messages.
